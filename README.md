# Interactive Drawing Canvas 🎨

A browser-based interactive drawing application built using HTML5, CSS3, and JavaScript. This project allows users to draw freely and create basic shapes on a canvas with customizable colors and brush sizes.

## About the Project

The Interactive Drawing Canvas is a front-end practice project focused on exploring JavaScript interactivity and the HTML Canvas API. It provides a simple drawing environment where users can sketch, create geometric shapes, customize drawing settings, and clear the canvas.

## Features

- **Freehand Drawing:** Draw freely using mouse or touch input.
- **Shape Tools:** Create rectangles, circles, and straight lines.
- **Color Picker:** Choose custom colors for drawings and shapes.
- **Adjustable Brush Size:** Control stroke thickness using a size slider.
- **Live Shape Preview:** Preview shapes while dragging before completing them.
- **Clear Canvas:** Remove all drawings with a single click.
- **Responsive Layout:** Canvas and toolbar adapt to different screen sizes.
- **Touch Support:** Supports drawing interactions on touch-enabled devices.
